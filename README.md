Introduction
This free tool can help you convert  audio files to video files, so you can easily share your music with your friends. The tool supports various audio files, such as MP3, M4A, MIDI, WAV and more. By default, the output video have no pictures and contains only sound, however, with the "Image" option, you can choose an image file or a solid color as the background of the output video, the tool supports various image files, such as JPG, BMP, GIF, PNG and more. The output format is MP4 video. Audiofile converter

How To Use
Select an "Audio" file (such as *.mp3, *.aiff, *.amr, *.flac, *.m4a, *.mid, *.midi, *.ogg, *.wav, *.wma and more).
Select a value in the "Image" option. If you choice the "File" value, select an image file (such as *.jpg, *.bmp, *.gif, *.png and more).
Click the "Convert" button to start uploading your files.
Once the upload is complete, the converter will redirect a web page to display the conversion results.
